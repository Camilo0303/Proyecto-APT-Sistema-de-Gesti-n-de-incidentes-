# Interfaz SIGI

La interfaz utiliza React, Vite y React Router. Desde esta carpeta se inicia con `npm.cmd run dev` y se compila con `npm.cmd run build`.

El backend se inicia en otra terminal desde `backend` con `npm.cmd start`. Vite redirige las solicitudes `/api` al puerto 3001.

El [mapa del proyecto y guía de defensa](../README.md) describe los módulos y los ejemplos para explicar el código.
